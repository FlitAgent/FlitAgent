# Design files

These files are copied from the `@flit/design` package, version 0.1.0: the design tokens (`_tokens.scss`, `tokens.json`), the font-face rules (`fonts.css`), the fonts, and the FlitAgent mark. The admin scripts and styles in `src/` compile from them.

The design files are licensed GPL-2.0-or-later, like this plugin. The fonts are licensed under the SIL Open Font License 1.1; each licence is next to its font in `fonts/`.

Do not edit these files by hand: they are generated from that package.
